# 🌐 Portafolio Web Profesional

Bienvenido a mi proyecto de portafolio personal, diseñado para presentar mi perfil profesional, experiencia, proyectos y habilidades técnicas de manera moderna, clara y efectiva para reclutadores, clientes y equipos de tecnología.

Este sitio combina una experiencia visual sólida con una arquitectura funcional orientada a resultados, integrando comunicación con el visitante, almacenamiento seguro de mensajes y automatización del flujo de contacto.

## ✨ Características principales

- Interfaz de usuario interactiva y responsiva, construida para una experiencia fluida en dispositivos móviles y desktop.
- Backend serverless para la gestión del formulario de contacto, con validación y procesamiento seguro de mensajes.
- Persistencia de datos en la nube con Supabase y PostgreSQL para almacenar interacciones del formulario.
- Notificaciones automáticas por correo electrónico, incluyendo alerta al administrador y respuesta automática personalizada al cliente.
- Capas de seguridad integradas: restricción CORS, sanitización de entradas para evitar XSS y control de tasa por IP mediante rate limiting.
- Diseño enfocado en la imagen profesional del autor, con navegación clara y contenido orientado a oportunidades laborales.

## 🏗️ Arquitectura y tecnologías

| Capa | Tecnología | Descripción |
| --- | --- | --- |
| Frontend | React + Vite + Tailwind CSS | Aplicación SPA moderna, rápida y adaptable para una presentación profesional del perfil. |
| Backend | Node.js + Express (serverless) | API REST para manejar el envío, validación y procesamiento del formulario de contacto. |
| Base de datos | PostgreSQL + Supabase | Almacenamiento seguro y escalable de mensajes enviados desde el formulario. |
| Seguridad | CORS, sanitización, validación y rate limiting | Protección frente a abuso, entradas maliciosas e intentos de spam. |
| Despliegue | Vercel | Publicación del frontend y ejecución del backend serverless en entorno productivo. |
| Email | Nodemailer | Envío de notificaciones y autorespuestas con plantillas HTML. |

## 🧩 Visión general del proyecto

Este portafolio no solo funciona como carta de presentación digital, sino también como una demostración práctica de habilidades en desarrollo frontend, backend, integración de servicios, seguridad y despliegue web. La estructura fue pensada para reflejar un nivel de madurez profesional y un enfoque orientado a la calidad, el rendimiento y la experiencia de usuario.

La sección de contacto integra un flujo real de comunicación que permite:

1. Recibir mensajes desde el sitio web.
2. Validar y limpiar los datos del usuario.
3. Guardar la información en base de datos en la nube.
4. Notificar al propietario del sitio.
5. Responder automáticamente al remitente con una plantilla HTML.

## 🚀 Guía de instalación rápida local

Sigue estos pasos para ejecutar el proyecto en tu entorno local:

```bash
gh repo clone rondons-26/abp-m9-proyecto_portafolio
cd abp-m9-proyecto_portafolio
npm install
npm run dev
```

Una vez iniciado, la aplicación quedará disponible en el puerto de desarrollo de Vite, generalmente en:

```text
http://localhost:5173
```

Para compilar la aplicación para producción:

```bash
npm run build
```
